# Screenshots Checklist

Use this checklist to collect portfolio screenshots. No screenshot generation is
required by the application.

## Core Product

- Login page with RavenTech branding
- Dashboard overview with health/status cards
- Executive dashboard risk posture
- Investigation list with status and priority badges
- Investigation overview with readiness, stage, and workflow guidance

## Investigation Workflow

- Targets tab with authorized domain/IP/URL target
- Recon tab showing passive entities and partial warning handling
- Findings tab with severity, confidence, evidence, and remediation status
- Timeline grouped by investigation lifecycle
- Review board with case review/report approval/remediation validation queues

## Intelligence

- Correlations Cards view
- Correlations Graph view or clean degraded graph state
- Correlations Table view
- Evidence Intelligence recurring evidence overview
- IOC intelligence and related investigations
- Threat Intelligence indicators, campaigns, techniques, and infrastructure
- AI Analysis fallback with citations and clean provider status

## Reporting

- Reports tab with template selector and quality warnings
- Executive report preview
- Technical report preview
- Reporting Center with filters
- Export buttons for PDF, DOCX, HTML, and Markdown

## Governance And Operations

- Admin Settings feature flags/export controls
- Audit Log table and metadata preview
- Operations Center health/release/storage cards
- Demo Checklist with seed/clear controls
- Release metadata from `/api/v1/release`

## Capture Notes

- Use demo data only.
- Avoid showing secrets, tokens, or real API keys.
- Prefer screenshots that show defensive wording and `[DEMO]` labels.
- Keep browser width wide enough to show navigation and workspace content.
